### 💡 About RatelSlop
**RatelSlop** (casually styled as *"RatelSlop Studios"*) is **not** a company, registered business, or commercial entity. It is an informal, non-commercial collective moniker used by private hobby developers based in the Netherlands and Germany to build, test, and publish experimental software projects.

---

We do not apply a single blanket license to all projects. Instead, **licensing is determined on a per-repository basis**:

1. **Repository-Specific Licenses:** Each individual project repository contains its own `LICENSE` file defining the applicable terms (e.g., permissive open-source licenses such as MIT/Apache, copyleft licenses, or custom terms).
